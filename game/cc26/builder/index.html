Using your own sound file

  1. Keep it short (under a second is best for hits) and under 2 MB. mp3, wav and ogg all work.
  2. Put the file in a public GitHub repository.
  3. Use either address:
    • https://raw.githubusercontent.com/you/repo/main/sound.mp3
    • https://you.github.io/repo/sound.mp3 (with GitHub Pages on)
  4. Paste it above and press Test. If it says ready, it will work in the game.

Other sites often block games from loading their files ("CORS"). Those may still play, but without the game's pitch and stereo effects, or not at all. Make sure you have the rights to any sound you use: record your own, or use public-domain sounds (for example from the Internet Archive or Wikimedia Commons).
