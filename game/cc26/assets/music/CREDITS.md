# Music credits

Background music for DF Pong. Each track was trimmed of silence, given short fades, leveled to the
same loudness (−20 LUFS) and converted to 96 kbps MP3. Licences were checked on each item's page when
the tracks were added (October 2026). The game also plays four tracks it generates itself (Drift,
Tabletop, Arcade, Night Bus), which need no credit.

## Adding music

Only add recordings that are public domain, CC0, or CC BY (with a credit here). Both the composition and
the recording must be free to use. Keep files around 2–3 MB (96 kbps MP3), level them to about −20 LUFS,
and add a line to `manifest.json`.
